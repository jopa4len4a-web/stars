# ParadoxyStars — проект для Bothost

Все файлы приложения находятся в корне репозитория.

## Как работает заказ

1. Покупатель открывает Mini App из Telegram, вводит username получателя и количество Stars.
2. Базовая цена — 150 ₽ за каждые 100 Stars. В админке задаётся процент комиссии Platega, который добавляется к сумме покупателя.
3. После нажатия «Создать заказ» заказ сохраняется, Mini App закрывается, а бот присылает детали и кнопку оплаты Platega.
4. Platega отправляет callback на `/api/platega/callback`. Сервер проверяет заголовки `X-MerchantId` и `X-Secret`, статус `CONFIRMED`, сумму и валюту.
5. Только после подтверждения оплаты запускается доставка через настроенный сторонний Fragment API. Статус доставки подтверждается по ответу поставщика.

## Развёртывание

1. Загрузить все файлы из архива в корень GitHub-репозитория.
2. В Bothost выбрать репозиторий и ветку `main`.
3. Указать переменные `BOT_TOKEN`, `APP_URL`, `ADMIN_USERNAME=ownerparadoxy`, `ADMIN_TELEGRAM_ID` (рекомендуется числовой ID), `MASTER_KEY` и `PORT`.
4. Команда запуска: `uvicorn main:app --host 0.0.0.0 --port $PORT`.
5. Убедиться, что работает только один экземпляр приложения с long polling для данного Telegram-бота.
6. Открыть `https://sellstarsss.bothost.tech/api/health` и проверить, что `status` равен `ok`, а `bot_token_configured` — `true`.

## Настройка Platega

1. В админ-панели ParadoxyStars введи Merchant ID и API Key (заголовок Platega `X-Secret`).
2. Выбери подключённый метод оплаты и укажи процент комиссии для покупателя согласно условиям своего договора Platega. По умолчанию комиссия 0%, чтобы не выдумывать тариф провайдера.
3. В кабинете Platega настрой callback URL как полный HTTPS-адрес `https://sellstarsss.bothost.tech/api/platega/callback`.
4. Callback должен передавать заголовки `X-MerchantId` и `X-Secret`; сервер сравнивает их с сохранёнными учётными данными.

Ключи интеграций шифруются в SQLite через Fernet. `MASTER_KEY` должен быть корректным Fernet-ключом и не должен меняться после сохранения секретов. Не публикуй API-ключи в GitHub.

## Настройка доставки

В админке введи URL и API key своего Fragment API-поставщика и выбери доступный тип баланса. Это сторонний совместимый API, не официальная публичная API Telegram. Для реальной доставки нужны действующий ключ и средства на балансе.

## Проверка перед запуском

- Проверь `/api/health`, `/api/catalog` и `/`.
- Создай тестовый заказ и убедись, что бот присылает детали и кнопку оплаты.
- Выполни тестовый платёж в Platega, проверь callback `CONFIRMED`, а затем убедись, что доставка действительно завершилась.
- Не принимай реальные платежи, пока полный путь не проверен на своём тестовом заказе. Я не могу проверить live-платёж без доступа к твоим Bothost/Platega аккаунтам и ключам.
